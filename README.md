# Shake Lock: downloads

Shake Lock is an Android app for phones with a broken power button: shake the phone twice quickly to lock the screen.

This repo only holds the app's APK downloads. The Shake Lock app checks it for in-app updates.

## Install

1. Open the **[latest release](https://github.com/mrzoro14/ShakeLock-releases/releases/latest)** on your phone and download `ShakeLock.apk`.
2. Open it and allow **Install unknown apps** when asked.
3. Open **Shake Lock**, pick a lock method, and follow the steps on screen.

From v1.4 on, you can update from inside the app: **Check for updates → Update**.

Requires Android 9 or newer.
